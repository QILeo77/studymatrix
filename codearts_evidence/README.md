本项目【智学矩阵 StudyMatrix】从架构设计到最终部署，全流程基于华为云码道（CodeArts）代码智能体开发完成。以下为核心开发留痕截图：

01_工程架构与初始化.png：使用码道生成模块化的 Flask 项目结构，搭建多 Agent 隔离目录。

02_多Agent路由与工具调用.png：实现 Router Agent 意图分发与 Planner Agent 计划生成逻辑，并完成端到端测试。

03_KaTeX公式渲染接入.png：使用码道解决大模型输出微积分公式无法渲染的问题，提升教育场景体验。

04_SQLite数据库迁移.png：在码道辅助下完成底层数据存储从 JSON 向 SQLite 的无缝升级，保障数据并发安全。

05_移动端自适应与抽屉布局.png：通过码道生成响应式 CSS 与 JS，完成移动端抽屉菜单及数据看板的适配。

06_艾宾浩斯与Prompt工程.png：将艾宾浩斯遗忘曲线与 SM-2 算法融入 Prompt 引擎，展现高级提示词工程能力。
